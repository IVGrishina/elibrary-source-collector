# Скилл: научный обзор литературы по дайджесту eLIBRARY

## Вход

Файл `data/processed/digest_<stamp>.md` — результат обработки в приложении:
- тема и массив публикаций (название, авторы, журнал, год);
- полная аннотация и ключевые слова каждой карточки;
- ссылка на публикацию: `https://elibrary.ru/item.asp?id=…`.

Ищите самый свежий `digest_*.md`, если пользователь не указал stamp явно.
Если файл не найден — попросите пользователя открыть приложение, загрузить карточки
и скачать «Дайджест аннотаций (.md)».

## Что делать

1. Прочитать дайджест целиком (входные данные только из файла — ничего не додумывать;
   фактов, отсутствующих в аннотациях, не выдумывать).
2. Сгруппировать публикации в 2–4 смысловых кластера по тематике (по аннотациям и ключевым
   словам), назвать каждый кластер.
3. Написать **краткий обзор литературы по теме набора** (2–4 абзаца в научном стиле):
   - что и в каких аспектах исследуется в массиве;
   - какие подходы/методы/результаты встречаются;
   - какие сюжеты, судя по массиву, проработаны слабее (строго по доступному материалу).
4. По тексту дать **внутритекстовые ссылки на источники** — в формате `[(Фамилия, год)]`,
   рядом — ссылку на публикацию eLIBRARY в скобках или сноской-списком в конце абзаца.
5. Завершить **таблицей источников**: №, авторы, название (со ссылкой), журнал, год,
   ключевые слова, краткое содержание.
6. Сохранить результат в `drafts/review_<stamp>.md` (тот же stamp, что у дайджеста;
   `drafts/` — локальная папка, в git не входит и не публикуется).
7. В отчёте пользователю: путь к файлу, объём, список кластеров и честные ограничения
   (обзор написан только по загруженным карточкам: N из 1000).

## Стиль

- Научный, без канцелярита и оценок вне материала аннотаций.
- Цитировать только источники из дайджеста; выдуманные данные недопустимы.
- Русский язык; имена файлов — латиницей.

## Связь с субагентом

Если в проекте доступен субагент-райтер (например, `writer-reg-econ` — Agent tool),
рекомендуется поручить написание текста ему, передав путь к дайджесту и разделы этого скилла
как инструкцию. Claude Code выполнит скилл и без него — по инструкциям выше.

Связанный скилл: `elibrary-source-collector` (запуск и доработка самого приложения).
Оба скилла публикуются в каталоге `skills/` репозитория проекта.
