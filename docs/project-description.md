# Описание проекта (для Зерокодер, финальный проект)

## Название
**eLIBRARY Source Collector** — собирает источники литературы на заданную тему из eLIBRARY (до 1000 источников) и готовит таблицу обзора и саммари.

## Проблема
Поиск в eLIBRARY источников литературы на заданную тему даёт сотни записей; вся содержательная обработка (авторы, релевантность теме и актуальность, сортировки, оценка цитируемости в том числе по ядру РИНЦ, таблица) — вручную, часы и дни на каждый обзор литературы.

## Пользователь
Исследователи/научные сотрудники, консультанты и аналитики, студенты и аспиранты, преподаватели.

## Основная функция
- **На входе:** HTML-страницы результатов поиска eLIBRARY («Список публикаций»), сохранённые из браузера (Ctrl+S → «Веб-страница, полностью»; загружаются только файлы .html), + по желанию карточки отдельных статей (тоже HTML).
- **На выходе:** структурированная таблица источников (CSV и Excel) с полями: название, авторы, журнал, год, том/номер, страницы, число цитирований, доступ к полному тексту; и отчёт-саммари с распределениями по годам и журналам, топом цитируемых публикаций и выводами.
- **Инструменты:** Python 3, локальное веб-приложение (браузер) для загрузки файлов и просмотра результата.

## Формат результата
1. Таблица источников — открывается в Excel, готова к переносу в Word.
2. Отчёт-саммари — статистика массива источников и выводы для начала обзора литературы.

## Минимальный функционал (MVP)
Реализовано на текущий момент:
- парсер HTML-списков публикаций: 100/100 полей с каждой страницы, устойчивость к особым случаям (записи без страниц/авторов, смешанная кодировка);
- обогащение таблицы из карточек статей: аннотации, ключевые слова, цитирования по ядру РИНЦ;
- генератор саммари: распределение по годам и журналам, топ-15 по цитированиям, выводы;
- дайджест аннотаций: суть каждой аннотированной публикации и ссылка на неё в eLIBRARY, частотная тематика массива;
- вывод в CSV и Excel; выбор порядка вывода источников;
- веб-интерфейс: загрузка файлов, догрузка карточек к существующей сессии («Дополнить набор»), скачивание результатов.

Планируется после MVP: обзор литературы по всему массиву, подготовленный ИИ-субагентом по дайджесту аннотаций (сейчас — во время работы в Claude Code, субагент-райтер); поддержка других источников публикаций с сохранёнными страницами (в первую очередь ResearchGate); экспорт списка литературы в формате ГОСТ; поддержка PDF-версии списка.

## Технологии
- **Python 3.12** (стандартная библиотека: `re`, `csv`, `html`, `argparse`)
- **Flask** — минимальный веб-интерфейс (в разработке)
- **openpyxl** — выход в Excel
- Форматы: CSV (UTF-8-BOM), XLSX, Markdown
