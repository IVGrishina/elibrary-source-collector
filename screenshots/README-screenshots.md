# Скриншоты демонстрации

В эту папку складываются скриншоты для демонстрации проекта.

Рекомендуемая серия:

1. `01-search-elibrary.png` — поиск по теме на сайте eLIBRARY.RU
2. `02-save-page.png` — сохранение страницы результатов (Ctrl+S → HTML)
3. `03-upload-form.png` — стартовый экран с окном выбора файлов
4. `04-result-tiles.png` — плитки показателей и распределение по годам
5. `05-result-table.png` — таблица источников (сортировка «по цитированиям»)
6. `06-sort-options.png` — блок выбора порядка вывода
7. `07-excel-table.png` — итоговый Excel в Microsoft Office
8. `08-excel-annotated.png` — записи с аннотациями и ядром РИНЦ

⚠️ В кадр не должны попадать файлы с личными данными сессии eLIBRARY
(имя пользователя, SPIN-код, IP) — сырые HTML-файлы и их содержимое.
