# Скриншоты демонстрации

Полный набор скриншотов демонстрации, структурированный по разделам пользовательского сценария.
Серия, вставленная в README репозитория (8 снимков), отмечена звёздочкой ★.

## Разделы

1. **01-search/** — поиск источников на eLIBRARY.RU
   - `01-search-elibrary.png` ★ — форма поиска с запросом по теме
   - `02-search-elibrary.png` — страница результатов нейропоиска
   - `03-search-elibrary.png` ★ — подборка «кадры сх регионов»: 1000 из 1000 публикаций
2. **02-save/** — сохранение страниц результата
   - `04-save-page.png` ★ — сохранение страницы результата (Ctrl+S)
3. **03-upload/** — загрузка файлов в приложение
   - `05-upload-form.png` ★ — стартовый экран с инструкцией
   - `06-upload-form.png` — выбор 16 сохранённых страниц
4. **04-results/** — страница результата
   - `07-result-tiles.png` ★ — плитки показателей и распределение по годам
   - `08-result-table.png` — блок «Наиболее цитируемые публикации»
   - `09-sort-options.png` — основные журналы и порядок вывода «как в подборке»
   - `10-sort-options-cite.png` ★ — порядок «по цитированиям» и таблица источников
   - `11-sort-options- save-page.png` — порядок «как в подборке» и таблица источников
5. **05-digest/** — дайджест аннотаций и догрузка
   - `12-to-save-results.png` ★ — блок «Скачать результаты» и начало дайджеста
   - `13-abstracts.png` — дайджест «О чём повествуют статьи» (полные аннотации)
   - `16-add-publications-options.png` — блок «Дополнить набор»
6. **06-export/** — выгрузка таблиц и файлов
   - `14-excel-table.png` ★ — итоговая таблица в Microsoft Excel
   - `15-excel-annotated.png` — записи с аннотациями и ядром РИНЦ
   - `17-result-digest.png` — файл дайджеста `digest_*.md` в редакторе
7. **07-review/** — обзор литературы (полный цикл)
   - `18-general-result-review.png` ★ — обзор, подготовленный субагентом по дайджесту

⚠️ В кадр не должны попадать файлы с личными данными сессии eLIBRARY
(имя пользователя, SPIN-код, IP) — сырые HTML-файлы и их содержимое.
При просмотре снимков `13-abstracts.png` и `16-add-publications-options.png` учтите:
в тексте аннотации виден небольшой артефакт самой страницы eLIBRARY (фрагмент кода
`function show_abstract…`); это след исходной страницы, а не ошибка парсера.
