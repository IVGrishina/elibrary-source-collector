Источники литературы из eLIBRARY.RU: таблица обзора и саммари за пару минут

  1. Найдите источники по вашей теме в eLIBRARY.RU (до 1000 публикаций).
  2. Сохраните страницы результата поиска: Ctrl+S → веб-страница, полностью (загружать в приложение — только файлы .html; папку ресурсов прикладывать не нужно).
  3. По желанию — сохраните HTML-карточки отдельных статей: из них будут извлечены аннотации и ключевые слова.
  4. Загрузите файлы сюда и получите таблицу источников со статистикой.
  5. Карточки можно догрузить позже — кнопкой «Дополнить набор» на странице результата (сессия сохраняется).

Файлы обрабатываются локально, никуда не отправляются. Поддерживаются сохранённые страницы «Список публикаций» в формате HTML.
